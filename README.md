# CRUD USUARIOS

Este é um aplicativo mobile desenvolvido com **React Native** utilizando o framework **Expo**.

## ✅ Pré-requisitos

Antes de começar, você precisará ter instalado em seu ambiente:

- [Node.js](https://nodejs.org/)
- Aplicativo **Expo Go** instalado no seu celular:
  - [Play Store (Android)](https://play.google.com/store/apps/details?id=host.exp.exponent)
  - [App Store (iOS)](https://apps.apple.com/app/expo-go/id982107779)


## 🧰 Tecnologias Utilizadas

- **React Native** — Framework para desenvolvimento mobile com JavaScript
- **Expo** — Plataforma para facilitar o desenvolvimento, build e deploy de apps React Native
- **React Hook Form** — Biblioteca para gerenciamento de formulários
- **Yup** — Validação de dados de formulários
- **React Native Elements** — Biblioteca de componentes UI para React Native
- **Context API** — Para gerenciamento de estado global


## ▶️ Como rodar o projeto

1. **Clone o repositório:**

```bash
git clone https://github.com/warleyramires/crud-users
cd crud-users
```

2. **Instale as dependências**
```bash
npm install
```

3. **Startar servidor Expo:**
```bash
npx expo start
```

4. **Abra o app no celular com Expo Go:**
- Após rodar o comando acima, será aberta uma aba no navegador com um QR Code.

- Escaneie o QR Code com o app Expo Go no seu celular.

- O aplicativo será carregado no seu dispositivo.
